## 6.2 Histogrammfunktion

- Häufigkeitsverteilung eines Merkmalswertes (z.B. Grauwert)
- [[1. Digitale Bilder Grundbegriffe|Grauwertbild]] mit $I(u,v) \in [0, K-1]$
  - Histogramm mit $K$ Einträgen, z.B. $K = 256$
- Histogramm-Eintrag: $h(i) = \text{card}\{(u,v) \mid I(u,v) = i\}$
  - Pixelzahl mit Intensitätswert $i$; $0 \leq i \leq K$

![[6-page_3_Figure_6.jpeg]]

### 6.2.1 Histogramm berechnen

```java
// Annahme: Bild mit 256 Graustufen
// Diese Funktion gibt das Histogramm des Bildes als Feld zurück
int[] histogram(Image image) {
    int[] H = new int[256]; // Erstelle Histogramm-Feld mit 256 Zellen
    int w = image.getWidth(); // Ermittle Bildbreite
    int h = image.getHeight(); // Ermittle Bildhöhe
    // Durchlaufe alle Pixelpositionen (u,v) des Bildes
    for (int v = 0; v < h; v++) {
        for (int u = 0; u < w; u++) {
            int i = image.getFixed(u,v); // Hole Pixelgrauwert i an der Position (u,v)
            H[i] = H[i] + 1; // Erhöhe den Zähler für den Wert i im Histogramm
        }
    }
    return H; // Gib Histogramm-Feld zurück
}
```

### 6.3.4 Dynamik

Anzahl verschiedener Pixelwerte im Bild:

- **Hohe Dynamik** — Ideal: Alle möglichen Pixelwerte werden ausgeschöpft $a_{1}$
- **Niedrige Dynamik** (64 Werte) $b_{\cdot}$
- **Sehr niedrige Dynamik** (6 Werte) $C_{\cdot}$

> [!tip] Merke
> Hohe Dynamik bei Bildaufnahme verringert Gefahr des Qualitätsverlusts durch nachfolgende Bearbeitungsschritte.

![[6-page_10_Figure_5.jpeg]]

- Kontrastumfang der Szene übersteigt den des Bildsensors $\Rightarrow$ Spitzen an den Rändern des Histogramms
- Sättigung am rechten Histogrammrand $a.$
- Löcher durch Kontrasterhöhung $b_{\cdot}$
- Spitzen durch Kontrastreduktion $C_{-}$

## 6.4 Binning — Histogramme für große Wertebereiche

### 6.4.1 Problem und Lösung

> [!abstract] Definition: Binning
> Teile den Wertebereich in $B$ gleich große Intervalle (Bins) und ordne jedes Pixel dem passenden Intervall zu. Eine Histogrammzelle (Bin) enthält die Anzahl der Pixel eines Intervalls.

- **Problematisch:** Histogramm-Darstellung bei hoher Intensitätstiefe, z.B. 16 Bit/Pixel $\Rightarrow$ 65.536 Histogrammzellen
- **Lösung:** Klassenhistogramm (Binning)

### 6.4.2 Berechnung

- Histogrammgröße $B$: Anzahl der Bins, z.B. $B = 256$
- Intervalllänge: $k_B = K/B$ ($K$: Anzahl Graustufen insgesamt)
- Startwert des Intervalls $j$: $a_j = j \cdot k_B$

> [!abstract] Definition: Bin-Inhalt
> Das Bin $h(j)$ enthält die Anzahl der Pixel mit Werten aus $[a_j, a_{j+1})$:
> $$h(j) = \text{card}\{(u,v) \mid a_j \leq I(u,v) < a_{j+1}\} \quad \text{für } 0 \leq j < B$$

> [!tip] Indexbestimmung
> Bestimmung des Index $j$ der Histogrammzelle aus dem Pixelwert $i$:
> $$j = \text{floor}\!\left(\frac{I(u,v)}{k_B}\right) = \text{floor}\!\left(\frac{I(u,v) \cdot B}{K}\right)$$

### 6.4.3 Beispiel

- Bild mit 14 Bit/Pixel, d.h. $K = 2^{14}$ und Werte im Intervall $[0, 2^{14}-1]$
- $B = 256$ (256 Zellen)
- Länge des Intensitätsintervalls: $k_B = K/B = 2^{14}/256 = 64$
- Intervallstartwerte: $a_j = j \cdot k_B$
$$a_0 = 0; \quad a_1 = 64; \quad a_2 = 128; \quad \ldots; \quad a_{255} = 16320$$

### 6.4.4 Programmbeispiel Binning

```java
int[] binnedHistogram(Image im) {
    int K = 256; // Anzahl Intensitätswerte
    int B = 32;  // Histogrammgröße
    int[] H = new int[B]; // Histogramm
    int w = im.getWidth();  // Ermittle Bildbreite
    int h = im.getHeight(); // Ermittle Bildhöhe
    // Durchlaufe alle Pixelpositionen (u,v) des Bildes
    for (int v = 0; v < h; v++) {
        for (int u = 0; u < w; u++) {
            int a = im.getFixed(u, v); // Hole Pixelgrauwert a an der Position (u,v)
            int j = a * B / K; // Ermittle Zellenindex im Histogramm
            // Nur Integeroperationen, daher keine explizite floor()-Funktion nötig
            H[j] = H[j] + 1; // Erhöhe den Zähler für Intervall j im Histogramm
        }
    }
    return H;
}
```

## 6.6 Kumulatives Histogramm und Normalisierung

### 6.6.1 Kumulatives Histogramm (Summenhistogramm)

$H(i)$: Summe der Häufigkeiten der Intensitätswerte $0$ bis $i$ (bezogen auf ein Bild). Monoton steigende Funktion.

$$
H(i) = \sum_{j=0}^{i} h(j) \quad \text{für } 0 \leq i < K
$$

- $H_{\text{max}}$: Gesamtzahl der Pixel eines Bildes mit der Breite $M$ und Höhe $N$

$$
H(K-1) = \sum_{j=0}^{K-1} h(j) = M \cdot N
$$

![[6-page_20_Picture_1.jpeg]]

![[6-page_20_Figure_2.jpeg]]

### 6.6.2 Normalisierte Histogramme

Normalisiertes Histogramm enthält relative Häufigkeiten:

$$
p(i) = \frac{h(i)}{M \cdot N}
$$

$M$ ... Bildbreite in Pixeln, $N$ ... Bildhöhe in Pixeln

$$
\sum_{i=0}^{K-1} p(i) = 1
$$

> [!question] Warum kann es sinnvoll sein, Histogramme zu normalisieren?
> - Vergleichbarkeit zwischen Bildern unterschiedlicher Größe
> - Wahrscheinlichkeitsinterpretation

### 6.6.3 Verteilungsfunktion

Pendant zum kumulativen Histogramm $H$: Kumulierte Wahrscheinlichkeitsdichte (nachfolgend kurz Verteilungsfunktion):

$$
P(i) = \frac{H(i)}{M \cdot N}
$$

$P(i)$ monoton steigend, es gilt:

$$
P(0) = p(0)
$$
und $P(K-1) = \sum_{i=0}^{K-1} p(i) = 1$

## Review & Learning

> [!summary] Zusammenfassung
> - **Histogramm** $h(i)$ gibt die Häufigkeit des Grauwerts $i$ an, verliert aber die Ortsinformation
> - **Binning** reduziert die Anzahl der Histogrammzellen durch Intervallbildung — wichtig für hohe Intensitätstiefen
> - **Kumulatives Histogramm** $H(i) = \sum_{j=0}^{i} h(j)$ ist monoton steigend
> - **Normalisiertes Histogramm** $p(i) = h(i)/(M \cdot N)$ ergibt relative Häufigkeiten, Summe $= 1$
> - **Verteilungsfunktion** $P(i) = H(i)/(M \cdot N)$ verbindet kumulatives Histogramm mit Wahrscheinlichkeit
> - **Farbbildhistogramme**: Luminanz, Komponenten ($h_R, h_G, h_B$), kombinierte Histogramme
> - Histogramminformationen: **Belichtung**, **Kontrast**, **Dynamik**, **Sättigung**, **Kompressionsartefakte**
